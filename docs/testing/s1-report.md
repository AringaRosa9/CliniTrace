## 已知边界

机构 OIDC 提供方、正式用户/项目映射、真实样本/授权仍依赖 FND-05；当前 OIDC 测试使用真实 RSA 签名的本地 token 和受控 JWKS 替身，不等同于机构联调。扫描/低质量文字层标记待 OCR，不能进入医学审核。S1 的成员配置是有审计的管理 CLI，尚无成员管理页面。

解析使用独立进程和资源上限；机构部署还需 OS/容器禁网、最小文件系统、恶意文件扫描、独立登录角色与密钥。PyMuPDF 的 AGPL/商业许可须纳入机构部署审查。保留失败原件、版本和审计；正式留存、备份与恢复演练仍属于 S5。详细限制及操作方法已写入运行手册。

当前测试依赖产生 Starlette httpx 接口及 PyMuPDF SWIG 的弃用提示，不影响现有验证结果；未隐藏这些提示。
