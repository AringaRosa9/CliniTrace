# S4 管理与质量闭环运行手册

本阶段提供模板、词库、金标准/裁决、评测报告和纠错二审。沿用项目 RLS、CSRF、审计和私有原件鉴权。页面：`/templates`、`/terminology`、`/quality`，以及相应 `/projects/[projectId]/…` 路由。

## 升级

```sh
uv sync --project backend --frozen
bash scripts/db/migrate.sh
uv run --project backend python scripts/db/bootstrap_s1.py
pnpm build
```

迁移 `0007_quality` 新增 12 张 S4 表。除模板草稿外所有版本/决定/样本均由数据库触发器禁止更新和删除；RLS 限制租户和项目。bootstrap 只针对本地合成环境，刷新开发角色及管理能力。机构部署按 `scripts/db/provision_member.py` 的清单分配权限，不运行合成 bootstrap。生产角色应获得 S4 表 SELECT/INSERT 与 `template_drafts` UPDATE 权限，不授予其他 S4 表 UPDATE/DELETE，也不能绕过 RLS。

新增能力：`templates.manage`、`terminology.manage`、`terminology.map`、`quality.read`、`quality.errors.read`、`quality.annotate`、`quality.review`、`quality.adjudicate`、`quality.manage`。涉及样本/原始事实的操作还需要 `original.read`；映射页面病例列表沿用 `review` 能力。`quality.read` 只返回报告与摘要，不包含错误样本、患者清单或预测原文。错误样本、冻结 manifest、纠错清单读取追加审计。

## 模板和术语

模板页面载入门诊/检验基础 Schema，表单编辑必填、数组约束、字段说明，JSON 编辑完整 Schema、枚举及正反例，维护指南和证据要求。保存带预期修订号，过期修改返回 409；发布再次进行 Schema/兼容性/示例校验。已发布版本不可覆盖。

P0 保持两类事实抽取适配器的语义结构。可收窄数组约束、补充说明和指南；事实的缺失原因/否定等语义枚举必须完整保留；不能删去证据约束、替换类型、添加适配器不支持的字段。新类型需先升级适配器。仅允许本地 `$defs` 引用，禁止远程 Schema 引用。抽取内容中的 `schema_version` 仍指基础语义契约 1.0.0；运行配置单独固定模板发布版本、指南版本和 digest，不混淆两者。

词库导入 JSON 包含版本、体系、授权引用、synthetic 标志，以及 `code/display/aliases/context` 条目。授权引用为空可导入待办，但不能激活或确认映射。生产禁止合成词库。激活影响之后创建的抽取，旧运行冻结词库内容和 hash。检索提供消歧依据；人工可确认、拒绝、保留待映射。确认编码必须存在于指定版本。每次映射绑定事实修订并记录理由、人员和序号，使当前审核失效；新事实修订不会继承旧确认。

## 金标准和纠错

依据 [采样计划](../data/s4-sampling-plan.md) 登记来源、授权、难例、患者组和 split。标注 JSON 使用生成契约的 `Labels`，事实与审核工作台共用证据格式。页面提供完整解析原文、页/块/span/bbox 和固定指南。合成抽取产生的样本必须显式标记 synthetic。

标注、独立二审、第三人裁决依次追加记录；角色授权不能豁免同人限制。冻结前必须达成一致或完成裁决。同一患者/患者组跨 split 被拒绝；一份清单不可混合 train/dev/test/external。最多 300 份/版本，后续规模扩展需另行评估。

工作台纠错自动进入候选池，独立二审后才可发布。登记 train/dev 患者组后选择已接收候选，点击“检查污染并发布纠错版本”。测试/机构外患者禁止回流；发布后也禁止把同一患者组登记到测试集中。变更失败请保留输入、刷新并检查状态；不要用另一患者组标识绕过冲突。

## 评测、重放及指标

选择冻结数据集，以 `sample_id → extraction_run_id` 指定预测。服务端验证覆盖全部样本，且运行属于同文书和患者。只取原始抽取事实，不把人工纠错混为模型预测；失败/取消运行按空预测计入。每份最多 500 条金标准事实、300 份/评测，当前在受限请求中完成离线指标计算，没有模型调用；更大规模应迁移到独立队列。

同数据集、同口径可以对比运行。报告显示样本量、事实分母、dataset digest、模型/提示词/Schema/指南/词库/解析器配置及高风险计数。取出获准重放输入：

`GET /api/v1/projects/{project_id}/quality/evaluations/{id}/errors`

将响应保存到获准本地目录，再离线重放：

```sh
uv run --project backend python evaluation/runners/evaluate.py /approved/evaluation.json --output /approved/replayed.json
```

runner 校验冻结输入 hash 和口径，重新计算并与已存报告比较；篡改或不一致以非零退出，不访问网络。输出文件包含受控样本信息，不提交真实病例。详细指标口径见 [metrics/README.md](../../evaluation/metrics/README.md)。

审核工作台以用户操作记录活动区间，超过 60 秒无操作的区间剔除；保存时追加累计差值，重试不重复计时。多文书范围均分耗时。标注、二审、裁决活动时间另列。模型费用来自 extraction measurements；没有完整测量显示 N/A，不能把 OCR/基础设施费用假设为零。合成模型不调用付费服务。当前版本不制定或声称达到临床高风险阈值。
