# S2 抽取运行手册

S2 工程管线已接通。默认仍为 `EXTRACTION_PROVIDER=disabled`、`OCR_PROVIDER=disabled`，本次没有更改用户 `.env`，没有调用付费或外部模型。机构服务、真实样本、正式词库与预算决策仍按 ADR-0004 执行。

## 启动与升级

先停止旧 API/Worker，执行以下兼容扩展迁移并重新赋予新增表权限，再启动 API、Worker 和投递器：

```sh
bash scripts/db/migrate.sh
uv run --project backend python scripts/db/bootstrap_s1.py
bash scripts/dev/api.sh
# 另开终端
bash scripts/dev/worker.sh
# 另开终端
bash scripts/dev/dispatcher.sh
```

迁移 `0004_extractions` 增加抽取账本、事实、证据、多对多关联、事实关系、有效运行与审核范围；`0005_measurements` 保存每次尝试的耗时、用量与受控原始响应引用。所有临床表执行项目 RLS，原始运行、事实、证据、结果、度量不可更新或删除。后台任务继续使用同一 `parsing` 队列，根据数据库 `jobs.kind` 分派到解析或抽取子进程。旧 Worker 不支持新任务，升级时必须同时重启。

## 本地 OCR

在受控机器安装 Tesseract 5 和所需语言包。中文默认 `chi_sim+eng`，用 `tesseract --list-langs` 确认两者存在；自定义语言目录可通过 Worker 环境 `TESSDATA_PREFIX` 指定。程序不自动联网下载语言包。

```dotenv
OCR_PROVIDER=tesseract
OCR_LANGUAGE=chi_sim+eng
OCR_TIMEOUT_SECONDS=30
```

新上传的图片、扫描或混合 PDF 在解析子进程中逐页识别；已有文字质量足够的页面保留文字层。既有 S1 扫描件可以在详情页点击“识别扫描文字”，新建解析任务和产物，不覆盖旧解析版本。已经存在抽取运行的文书禁止重解析和更正归属，防止改变审核来源；S3 保持此限制，未抽取文书的关联更正会使相关审核范围失效。

TSV 行单元格、原始识别文本、归一化 bbox、全局 Unicode offset、引擎版本、语言及置信度质量信号随解析版本保存。表格采用按行排列的单元格重建，**不承诺合并单元格、复杂跨页表格或医学字段语义对齐**；事实配对仍由 Schema 实体组和人工复核约束。空页保持 `needs_ocr`，不能开始抽取；低质量识别生成不可豁免的复核问题。

单页 OCR 默认 30 秒，总任务默认 180 秒。超时杀死整个进程组，避免残留 Tesseract。Linux 子进程地址空间 2 GiB、CPU 170/175 秒，保留 S1 页数、像素、页图和文件限制。正式部署仍需 OS/容器级网络、内存和文件权限隔离。

## 合成工程验证

```dotenv
EXTRACTION_PROVIDER=synthetic
ALLOW_SYNTHETIC_MOCK=true
TERMINOLOGY_VERSION=synthetic-terms-1.0.0
```

此模式使用明确的测试语法，不是临床模型。文书必须以 `SYNTHETIC-S2` 开头。可使用 `tests/fixtures/synthetic/s2-outpatient.txt` 与 `s2-laboratory.txt`。两份文件关联到同一患者/就诊，解析后点击“开始抽取”。界面会明确显示合成模式；生产启动拒绝 synthetic 身份、抽取和词库。

## 获准模型网关

网关是机构实现的受约束抽取 HTTP 接口，不默认绑定任何供应商，也不兼容未经适配的聊天接口。配置必须包含固定模型标识和授权引用；外部端点只接受 HTTPS，本地开发可使用 loopback HTTP。禁止重定向、URL 用户信息、查询参数及隐式代理；令牌只传请求头，不写入运行配置或对象产物。

```dotenv
EXTRACTION_PROVIDER=gateway
EXTRACTION_GATEWAY_URL=https://approved-host.example/extract
EXTRACTION_GATEWAY_TOKEN=由环境注入
EXTRACTION_AUTHORIZATION=机构批准记录引用
EXTRACTION_MODEL=固定模型版本
TERMINOLOGY_VERSION=unmapped-1.0.0
```

配置样例不是可用服务。默认预算仍为 0 CNY，**只能连接遵守 `max_cost_cny=0` 的零计费/机构本地网关**。应用不能阻止不遵守该契约的外部服务自行计费，因此网关必须在调用模型前执行预算门禁。付费预算与价格表尚未获批，不在本次实施中擅自开放。

请求为 JSON，包含 `model`、独立系统 `instruction`、完整 `schema`、`max_output_bytes`、`max_cost_cny`、幂等 `request_id`、`data` 和 `repair`。`data` 包含文书版本、解析版本及文本/页面/块；文书内容为不可信数据，无工具定义或任意网络执行能力。结构修复请求另带 `invalid_output` 和 `repair_instruction`，同一 generation 最多修复一次。

网关返回：

```json
{
  "model": "固定模型版本",
  "request_id": "供应方请求标识",
  "finish_reason": "stop",
  "output": {"schema_version": "outpatient-1.0.0", "diagnoses": [], "history": [], "medications": [], "duration": []},
  "usage": {"input_tokens": 123, "output_tokens": 45, "cost_amount": "0", "cost_currency": "CNY"}
}
```

`output` 必须符合固定门诊/检验 Schema，空数组会产生阻断项，不会自动审核。模型版本不符、截断、无用量、超预算、结构不合法、缺证据或引文/版本/坐标不符均失败。最多输入 60,000 字符、响应 2,000,000 字节；默认请求 30 秒、每分钟 10 次、同网关最多 2 个在途调用，Redis 在进程间共享限额。暂时失败可按任务重试规则显式重试；没有隐藏的网络重试循环。响应原文及每次尝试记录到私有对象/账本；超时或进程崩溃而未取得响应时，用量保持未知，不填 0。

## 事实、证据、规则和版本

- 固定输入摘要、解析/模板/Schema 摘要、模型、提示词、规则、词库版本与配置。执行前发现配置漂移，报 `RUN_CONFIGURATION_CHANGED`，需要新建运行。
- 引文必须精确匹配 Unicode code point 半开区间，并属于该解析版本、该页、该文本块；坐标只能使用解析器位置。允许同一事实多证据和一条证据关联多事实。
- 保留数值字符串、比较符、原始单位；数值不得改写为证据中不存在的值。相对时间不推导日历日期，不猜测剂量。
- 重复实体使用独立内部实体键；药名—剂量/频次、检验名—结果/标本/方法关系指向具体事实键。
- 规则覆盖缺失剂量/单位、未知、否定、日期、重复、跨文书冲突、低质量 OCR 和待映射。问题带严重度及是否可有理由接受未知；问题处置和最终审核已在 S3 实现，见 [S3 运行手册](s3.md)。
- `unmapped-1.0.0` 保留待映射；开发词库仅含 `LOCAL-SYNTHETIC` 编码。没有加载或编造 ICD/LOINC 等正式编码，没有自动确认映射。
- 首个成功运行加入就诊待审核范围；后续成功运行仅为候选。显式“采用此版本”必须提交理由和期望范围版本，事务内重算问题并递增范围版本。没有人工审核完成/导出入口。
- 抽取失败、取消、租约过期和旧 Worker 不发布任何部分事实。原始响应与用量账本不等于有效事实。

## 接口与排错

运行接口见 `packages/contracts/openapi/runtime.json`：`extraction-config`、文书 `ocr`/`extractions`/`active-run`、`extractions/{run_id}`、就诊 `review-set`、`terminology/candidates`。任务仍通过既有 `jobs/{id}` 查询、取消和重试。

常见失败：`OCR_NOT_INSTALLED`/`OCR_ENGINE_FAILED` 检查二进制和语言包；`OCR_TIMEOUT` 拆分或检查资源；`MODEL_TIMEOUT`/`MODEL_UNAVAILABLE` 检查获准网关；`MODEL_RATE_LIMIT`/`MODEL_CONCURRENCY_LIMIT` 稍后重试；`MODEL_SCHEMA_INVALID` 检查网关输出；`EVIDENCE_*`、`NUMBER_WITHOUT_EVIDENCE`、`INFERRED_DATE` 检查抽取质量。日志不输出病历正文。

对象巡检 `scripts/db/sweep_objects.py` 已覆盖 `extracted/`，保留成功结果和失败度量引用的原始响应，其余孤立产物超过 24 小时才可清理。修改敏感数据留存或生产角色授权仍按机构配置执行。
