# ADR-0002：不可变修订、审核范围和证据坐标

状态：接受（工程设计）；医学模板发布前需医学复核。

采用稳定事实键 + 追加修订 + 显式就诊内审核集合。审核快照与导出清单冻结修订，修改使当前审核失效。事件时间不强转精确日期，否定与缺失语义独立。传输数值为十进制字符串。

证据 span 使用 Unicode code point 半开区间，不采用 JavaScript UTF-16 下标。共享夹具覆盖中文、emoji 及混合文本；Python 原生切片与 JavaScript Array.from 后切片必须一致。bbox 是旋转归一化页的左上坐标 [0,1]。实现参见 contracts/models.py、前端 evidence.ts 和共享 spans.json。

后果：解析器需要文本版本/映射与页变换矩阵；复核不能仅记录布尔值，导出不能实时查询可变事实表。
