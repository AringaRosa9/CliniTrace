# ADR-0004：本地合成开发基线与机构接入门槛

状态：开发基线已确定；机构正式决策待提供，不能由工程实现代签。

未获得机构身份源、词库许可、获准样本、模型供应方和预算。S0 本地基线为：synthetic 身份模式（S1 已提供显式开发登录和机构 OIDC 适配）、仅合成样本、无外部 OCR/模型、模型预算 0 元。开发不得因配置缺失自动切换供应方。

| 项目 | 开发确定值 | 进入真实处理前必需材料 / 责任 |
| --- | --- | --- |
| 身份 | synthetic 配置；生产拒绝 | OIDC issuer、audience、JWKS、回调、角色映射；OPS |
| 词库 | synthetic-terms-1.0.0，无正式编码 | ICD/LOINC/机构药品库明确 release、获取渠道、许可/使用范围、复核人；PM/MED |
| OCR | disabled，候选本地隔离运行 | 获准主机/地域、OCR 版本/许可、CPU/GPU、扫描样本质量报告；AI/OPS |
| 模型 | disabled，不发送任何文书 | 供应方、模型版本、处理地域、留存/训练条款、出网白名单、凭据托管；PM/AI |
| 样本 | synthetic-only-v1；来源为本仓生成，无真实患者 | 来源、用途、授权记录、患者分组、脱敏流程、标注/二审计划；PM/MED |
| 预算 | 外部调用 0 CNY；程序限制不可提升 | 每份、每天、每项目上限及成本计量规则；PM |

S0 样本只是工程正反例，不可用于模型效果或临床质量声明。S2 真实调用须另行完成批准；S4 正式词库发布须检查版本授权；S5 才进行机构试点准入。

默认工程资源：上传 20 MiB、100 页、单图 40MP、任务 180 秒、Worker 并发 2、尝试最多 3 次、结构修复最多 1 次、网络重试退避 1/2/4 秒（不重试语义错误）。S0 settings 验证限额合法，真正执行上传/解析/Worker 限额在 S1/S2；不得声称现在已有处理管线。开发 OCR 容器规划 2 CPU/4 GiB、无 GPU、无出网；经样本测量后调整。

样本扩展计划：门诊/检验各至少 50 份获准样本起步，按患者分组；覆盖否定、未知剂量、多药/多检验、方法缺失、重复词、多页/旋转、emoji、相对病程、冲突、低质图。先双人标注/裁决 20 份校准指南，再冻结测试清单与 hash；没有获准样本时只继续合成工程验证，不宣称质量达标。
