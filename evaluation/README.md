# 质量评测

状态：S0 已加入两类合成模板样例、工程样本 hash 清单和无正式编码的合成词库清单；尚未建立医学金标准或生成模型实测指标。

- `runners/`：离线评测、版本比较和重放入口。
- `metrics/`：字段、span、关系、时间、术语、高风险错误及成本指标。
- `datasets/manifests/`：可提交的去敏版本元数据和清单格式；含患者身份或受控对象地址的实际清单保存在获准环境。
- `datasets/synthetic/`：可提交的合成评测样本，须与真实数据明确区分。
- `reports/`：本地输出目录，默认不跟踪；经人工检查的匿名汇总再归档到 docs/testing。

训练／开发／测试按患者隔离，金标准需要标注、复核、裁决及冻结。纠错经二次复核才能进入候选数据集。实测报告必须记录版本、样本量和指标分母；原型模拟数值不作为基线。实施任务见 [开发计划](../DEVELOPMENT_PLAN.md) 的 QLT-03～06。
