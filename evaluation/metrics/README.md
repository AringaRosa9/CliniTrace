# 固定评测口径 quality-1.0.0

实现：`backend/app/modules/quality/metrics.py`；离线入口：`evaluation/runners/evaluate.py`。此版本不进行词义扩展或医学推断。

- 字段：按文书、字段路径、精确字符串标准值、类型、单位、比较符、缺失原因、断言和 experiencer 做多重集合匹配；保留 `7.0` 与 `7.00` 差异，不隐式合并重复预测。micro 汇总 TP/FP/FN，macro 对有定义的字段 P/R/F1 分别取均值。报告每字段和文书类型分层。
- 严格 Span：语义字段一致且证据集合的文书版本、文本版本、页码、Unicode code point 半开区间完全一致。宽松 Span：语义字段一致，同文书/文本版本/页有至少一个正长度交集；用最大二分匹配，每条预测最多匹配一次。多证据宽松匹配只要求一处交集，严格指标同时披露完整证据集合要求。
- 关系：有向类型加源/目标语义字段和证据锚点；不使用运行随机 UUID 作跨版本匹配键。报告 TP/FP/FN/P/R/F1。
- 时间：以金标准含时间的事实为分母，优先精确证据锚点、再同字段相交证据对齐，预测时间结构完全相等才算正确；精度、相对时间和原文保留，不自动补全日期。
- 术语：以有金标准 coding 的事实为分母，比较体系、版本、编码；报告正确率、覆盖率和拒答率。当前抽取只输出候选，候选不是人工确认，预测编码记 null，因此不能把候选召回率伪装成编码正确率。
- 高风险：否定变肯定的分母为金标准否定事实（精确或重叠证据对齐，避免边界偏移隐藏高风险）；剂量错误计金标准剂量缺失/不一致及额外预测剂量，分母为金标准剂量数加额外预测剂量数；患者串联按文书数量计。在线服务拒绝跨患者预测，独立 runner 也保留串联计数。
- 所有零分母显示 null / N/A。总体 F1 不替代高风险门槛。错误样本按 FP、FN、证据、关系、时间、术语、否定、剂量、患者串联分层，查看需额外授权。
- 耗时：抽取耗时来自全部 attempt；人工审核来自操作活动区间，标注活动时间单列，提供中位数与 nearest-rank P95。修改数来自不可变事实修订（含补录），退回率来自对应运行的退回审计。
- 费用：CNY 精确 Decimal，包含全部有测量的模型 attempt；任一文书费用缺失则总额 N/A。当前零计费模型网关及 synthetic 分别由运行配置/provider/usage 标识，OCR 与基础设施价格尚未获准，未给出成本估计。

每次评测冻结成员、预测、配置、用量、活动记录统计及输入 hash。之后审核或纠错不会改变已存报告；重新运行会形成新的报告与测量截点。
